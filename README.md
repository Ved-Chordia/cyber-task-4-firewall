# Cybersecurity Internship – Task 4

## Objective
Learn to configure basic firewall rules using Windows Defender Firewall and demonstrate control over network traffic.

---

## Tools Used

- **Platform:** Windows 10/11
- **Firewall:** Windows Defender Firewall with Advanced Security

---

## What I Did

1. Opened the Windows Firewall advanced settings.
2. Explored existing inbound rules.
3. Created a rule to block TCP port 23 (Telnet).
4. Verified the rule's presence in the list.
5. Optionally tested the block with `telnet` (if available).
6. Deleted the rule after confirmation.
